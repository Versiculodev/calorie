# Calorie

Log what you ate and see how many calories are left for the day.

```bash
npm install
npm start
```

`npm start` opens Expo. Press `w` for the browser, or scan the QR code with Expo Go.

- `npm run build` typechecks the app
- `npm test` checks the day and calorie math
- `npm run lint` runs the Expo linter
